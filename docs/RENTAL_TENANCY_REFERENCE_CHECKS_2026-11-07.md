# Rental tenancy preferences and manual reference checks

Applicant intake extends the existing six-step form. Primary applicant records intended total occupants and pet intention, with optional proposed start date and lease duration. Pets exclude assistance animals. Co-applicants provide their own personal details. Total occupants must not be fewer than adult applicants.

Each applicant separately opts in to reference contact. Consent is optional. Staff-only append-only logs record checks against a previous landlord, employer or personal referees, with factual outcomes, contact method and encrypted internal notes and evidence references. The application must be submitted, consent must be current and the relevant contact must be supplied. No automated tenant selection or reference contact is performed.

Migration 0048 adds guarded reference records. Privacy erasure removes the records. Existing production release gates are unchanged: rental intake, malware scanning and automated agency handoff remain disabled until separately accepted.
