# Rebuild leasing presentation and acceptance
The public directory and detail UI share the approved ProInspect colours and editorial typography. The five search categories remain presentation-only; the residential-only public publication and retired commercial route policies are unchanged. The known existing `lst_pr115_demo` fixture is separated from genuine results and labelled not available to rent. Its hosted registration, application and visitor check-in paths reject attempts; local fixture testing remains possible. Production-facing directory/detail views exclude that sample. No live database records, photographs, prices, or applicant data are created or changed.
Cards use published photo presence and upcoming session metadata from a single D1 query. Missing photos use a labelled neutral placeholder; missing image resources return 404. Application readiness is verified with the existing gated helper for up to six relevant internal-application listings per query; further listings direct visitors to check the property page rather than asserting availability. External URLs retain existing validation. The individual page reevaluates all existing application safeguards. Visitor check-in links are shown only within the existing valid session window. The historical category route returns to the same filtered directory, and search links preserve filters without accepting arbitrary redirect URLs.
Gallery tests use the actual React gallery in a browser with intercepted synthetic image requests, not public seeded photos. The hosted staging sample has no genuine property images or active leasing actions. Tests therefore verify that sample presentation and safe rejection, not a live completed applicant journey. Axe scans are automated WCAG checks, not formal certification; manual screen-reader and genuine populated-listing acceptance remain outstanding. Lab timings record the actual deployed source at baseline and final to avoid misleading comparisons if an intermediate revision deployed first.
